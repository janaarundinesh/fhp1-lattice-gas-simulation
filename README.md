# FHP-1 Lattice Gas Simulation

An individual scientific computing project implementing a
two-dimensional FHP-1 lattice-gas model in C, with MPI-based
parallelization and MATLAB visualization.

## Objectives

- Implement particle collision rules on a hexagonal lattice.
- Implement particle streaming and boundary conditions.
- Validate simulation correctness using automated tests.
- Parallelize the simulation using MPI.
- Evaluate performance using reproducible benchmarks.
- Visualize simulation output using MATLAB.

## Project status

Under development.

## Technologies

- C
- MPI (MPICH)
- MATLAB for visualization
